# 0004. Mod Save Side File

## Status
accepted

## Context
Моды хранят собственное состояние: прогресс обучения, активные события, характеры соперников, достижения, платформы. Сейв игры — `JsonUtility`-снимок `SaveObject` в `persistentDataPath/Saves/<name>.txt`. Классы сейва наследуют runtime-классы, так что поля можно было бы «подмешать» в игровые объекты. Но тогда сейв без мода или с другой версией мода может сломаться, а мод живёт в отдельной DLL (решение 0001).

## Decision
Состояние модов — в боковом файле `<saveName>.ptmod.json` рядом с сейвом: `{ "schema": 1, "modVersion": "x.y.z", "features": { "<feature-id>": { ... } } }`.
- Запись: postfix `SaveHandler.Save(string)`, атомарно (временный файл → rename). Автосейв (`autosave.txt`) получает `autosave.ptmod.json`.
- Чтение: `SaveHandler.OnLoaded`; секции раздаются фичам. Нет файла или секции — значения по умолчанию.
- Неизвестные секции (фича выключена или удалена) сохраняются без изменений.
- Миграции — по полю `schema` фичи.
- Удаление сейва из меню игры удаляет и боковой файл (postfix на удаление, если оно есть в `SaveSystem`).

## Consequences
- Плюс: сейвы игры остаются ванильными. Мод можно снять без потери прогресса игры.
- Минус: копируя сейв вручную, нужно копировать оба файла (в README).
- Фичи не добавляют поля в классы игры.

## Уточнения (mod-framework v0.2)
- Запись бокового файла — postfix `SaveSystem.Save`, а не `SaveHandler.Save` (патч P12): там известно итоговое имя сейва (включая фолбэк `Y_M_D`), и postfix не выполняется, если игра не записала `.txt`. Автосейв (`SaveHandler.Autosave` → `SaveHandler.Save("autosave")`) проходит через тот же `SaveSystem.Save`.
- Версию секции — поле `_schema` — пишет и читает ядро (`ModSave`), фичи своё поле версии не хранят. Секция без `_schema` читается как версия 1. Поле `schema` самого файла (формат бокового файла) остаётся на верхнем уровне.
- Глобальные данные профиля (достижения и т. п.) живут не в боковом файле, а в `ptmod_profile.json`, единственный писатель — `ModProfile` (с `.bak` и троттлингом записи).
