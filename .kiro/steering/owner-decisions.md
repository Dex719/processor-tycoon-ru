# Решения владельца (по умолчанию)

Дата: 2026-10-10. Владелец одобрил реализацию всех спек и загрузку Harmony. На открытые вопросы спек приняты ответы ниже. Любое решение можно переиграть: каскадом правятся `requirements.md` → `design.md` → `tasks.md`.

**Общее правило:** если в спеке у вопроса стоит «предложено: X», принимается X. Если варианта нет — выбирается самый простой безопасный, и решение записывается в спеке в раздел «Решения по умолчанию».

## Общие политики (для всех спек)

1. **Перемотка новой игры.** Фичи нейтральны: пока `DateController.Instance.IsFastFowardSimulating`, они не создают событий, писем и реакций и не применяют новых эффектов. Состояние, которое нужно ИИ к старту (архитектуры, платформы, характеры), инициализируется один раз на `DateController.OnFastFowardEnded`.
2. **Названия — реальные, как в русификаторе.**
   - Компании: Intel, AMD, IBM, Motorola, Cyrix, Zilog, Texas Instruments, TSMC, Apple, Dell, HP, Sony, Nintendo и т. д.
   - Архитектуры: x86, x86-64, ARM, MIPS, PowerPC, SPARC, RISC-V.
   - Соперники в GPU: NVIDIA, ATI, 3dfx, Matrox, S3.
   - Издания прессы — вымышленные: реальные бренды изданий не используем.
   - В контенте компании указываются по `UniqueID` / ключу исторической компании, а отображаемое имя берётся из игры.
3. **Одинаковые правила для ИИ и игрока.** Эффекты для ИИ на низкой сложности не ослабляем: сложность и так влияет на ИИ в игре.
4. **Предел суммарного эффекта.** Балансовый диапазон каналов `market.rating.cpu` и `popularity.gain` — **[0,5; 2,0]** на CPU, применяется в ядре. Explain показывает «(ограничено)». Каждая спека-поставщик указывает свой максимальный вклад.
5. **В ядро (`mod-framework`) переносятся общие механизмы:**
   - `ModSegments.Classify(Cpu)` — классификатор сегмента по цене, вместо копий в фичах;
   - `ModEvents.CpuReleased(ICompany, Cpu, bool isVariant, bool duringFastForward)` и `ModEvents.CpuTransferred` — один postfix ядра на `Company.AddCpu` / `AICompany.AddCpu`, фичи свои патчи на AddCpu не ставят;
   - `ModTicks.IsBatchRun` — пакетный прогон `DateController.NextMonth`;
   - **ModMail:**
     - многоразовые кнопки-действия (`ModMailAction`), неактивные варианты (`Enabled`, `DisabledReasonKey`), `Refresh`, `SetStatusLine`;
     - приоритет письма (Critical / Normal / Low) и квота на фичу; Critical идёт в обход дневного лимита;
     - письма различаются по `Tag`, блоков ID нет;
   - `ModModifiers`: `ModifierContext.Contract` (заполнен в P8), причины провайдеров для `Explain`, сброс кеша по запросу, канал на `CpuMath.ProjectCost` с контекстом проектируемого CPU (development.cost per-design);
   - `ModCredit.ThresholdOf(ICompany)` / `PlayerDebtLimit()` / `IsPerCompanyActive` — единый порог дефолта;
   - `ModReputation.Drift` — дрейф к 50 в ядре, без записи в историю;
   - `ModProfile` — глобальный профиль (достижения и т. п.) в ядре, с `.bak` и троттлингом записи;
   - `ModNewGame.RegisterSection(featureId, build, order)` и событие `PreviewChanged`. Опции фич в окне новой игры — на одной панели за кнопкой «Моды…»;
   - **версия секции сейва** — поле `_schema`, его пишет и читает ядро, фичи своё поле версии не хранят;
   - **каналы объявляются в реестре ядра** до `Register` фич: включая `production.memoryCost`, `production.waferCost`, каналы GPU и `acquisition.price`.
6. **Язык мода** — своя настройка, по умолчанию `ru`.
7. **Тулчейн** (решение 0003, обновлено): Roslyn `csc.exe` из Visual Studio 2022 Build Tools (уже установлен), C# latest, `/nostdlib` + ссылки на `Managed/*.dll`. .NET SDK не нужен.
   - Тесты чистой логики — свой мини-раннер на .NET Framework 4.8, без xUnit (без загрузок).
   - Тесты установщика — Python `unittest`.
8. **Harmony** — `Lib.Harmony` 2.3.x (одобрено), лежит в `mod/lib/` (в `.gitignore`). В релизах распространяется рядом с `PTMod.dll` с лицензией MIT.
9. **Распространение.** Готовые DLL — в GitHub Release. `install.py --with-mods` ставит их; если найден `csc`, умеет собрать сам.
10. **Установщик.**
    - Неизвестная версия игры — отказ без `--force`.
    - Режим `--mods-only` нужен.
    - Пример фичи `framework-sample` — только в отладочной сборке.
11. **Интерфейс и почта.**
    - Кнопка «Моды» — клон `DoorButton` на панели.
    - Почта после восстановления писем мода сортируется по дате.
12. **Каналы и кредит.**
    - Новые каналы `construction.cost` и `development.cost` утверждены.
    - `bank.creditLimit` по компании к порогам ИИ в `AIBehaviour*` **не** применяется.
    - Лимиты кредитов `bankruptcy-recovery` на `bank.creditLimit` не умножаются (без двойного применения).
    - `production.unitCost` — только фактические траты.

## По спекам

- **first-year-onboarding.**
  - Переключатель «Обучение» включён по умолчанию, только если профиль ещё не видел обучения.
  - Срок 730 дней.
  - Пауза при новом шаге включена.
  - Подсветка UI — Could, не входит в MVP.
- **scenarios-achievements.**
  - Годы старта 1975–2000 с шагом 5.
  - «Assisted» ставится:
    - сразу, если включены читы;
    - при выключении фич посреди сценария.

    Спасение `bankruptcy-recovery` assisted не ставит.
  - Кнопка «Следующий месяц» — не чит.
  - Понижать сложность во время сценария нельзя.
  - Assisted-достижения открываются с пометкой.
  - «В главное меню» — с подтверждением, без автосейва.
- **bankruptcy-recovery.**
  - Проценты начисляются раз в месяц.
  - Пол лимитов умножается на инфляцию.
  - Лимит спасений по сложности — `[2,1,1,1,1,0]`.
  - Доля инвестора идёт по статье `Royalties`.
  - Гарантированного OEM-контракта нет.
  - При выключении фичи в окне «Моды» во время игры непогашенный остаток переводится в обычный долг игры (после подтверждения в хабе). Заморозки нет — эксплойт закрыт. При удалении мода без выключения кредиты исчезают, README требует выключить фичу заранее.
  - Если фича выключена иначе (правка `ptmod_settings.json` вне игры, сейв загружен при выключенной фиче, мод удалён, фича недоступна), код фичи не вызывается и ничего не переводится. Ядро для этого не меняем (2026-10-11). Деньги кредитов остаются у игрока без долга, пока фича неактивна; при включении в окне «Моды» кредиты продолжаются с места остановки. README предупреждает: «выключайте фичу в окне «Моды» и перед удалением мода».
  - Досрочный выход из дефолта включён.
  - Черновые ставки и сроки приняты.
- **rival-acquisitions.**
  - Множители приняты.
  - Цена считается от капитала с кэшем цели: `P = max(E_min, m·(E + max(0, C)))·Ch·(1−σ_p)`. Инвариант `NetCash < 0` для Hostile / Distressed — арбитраж закрыт.
  - Спасение — prefix `AICompany.BankruptcyWarning`, до необратимых действий метода.
  - Сделки с уходом баланса в минус запрещены.
  - Дочки под старым брендом нет.
  - x86-лицензия при покупке не передаётся.
  - Антимонопольные ограничения — в `historical-events`.
  - Аукцион длится 365 дней.
  - Контракты цели переносятся.
  - Дивиденды — по статье `Interest`.
  - Продажи доли обратно нет.
  - `FoundryServices` включается, если он был у цели.
  - GPU-линейка передаётся, если включена `gpu-product-line`.
- **contract-transparency.**
  - Подтверждение — «только рискованные».
  - К проценту дописывается «(факт. N %)».
  - Ошибки игры объясняем, но не исправляем.
  - Проигрыши — одной сводкой в день.
  - Журнал: 500 записей и 10 лет.
  - Возможных конкурентов-ИИ показываем.
  - Термины сверяем с переводом `ptru`.
- **platform-generations.**
  - Вес сегмента «Промышленность» — 0,5; `sharedWeight` — 0,25.
  - Стандарт памяти влияет.
  - Контракты Calculator исключаются.
  - Ванильный PGA-переход остаётся.
  - Имена поколений — реальные сокеты.
- **research-tree-ux.**
  - Без компактной перекладки рядов.
  - Ширина боковой панели — Could.
  - «Просмотренные» хранятся в сейве.
  - Напоминания включены, пороги 7 и 30 дней.
  - Мост к `TooltipHandler` — в `ModUI`.
  - «Сравнить» — в `InspectorWindow`.
- **cpu-architectures.**
  - Лаборатория общая с исследованиями.
  - x86 без лицензии — с роялти, без запрета.
  - Утверждены 7 семейств и диапазон [0,80; 1,20].
  - x86/x86-64 при позднем старте даётся без исследования.
  - Предпочтения ИИ — по историческим компаниям.
  - Рейтинг — только провайдер стандартного канала `market.rating.cpu`.
  - Стоимость проекта — через канал ядра на `CpuMath.ProjectCost`.
- **event-system.**
  - Частоты приняты.
  - Модальное окно с паузой — только для important.
  - При загрузке события не перебрасываются.
  - Доходы — `RevenueOrigin.Interest`.
  - Журнал — 400 записей.
  - `EventAi.AddChooser` — список по убыванию приоритета, побеждает первый ненулевой ответ.
- **market-shocks.**
  - Частоты приняты.
  - Есть уровень «Хаос» ×2 (настройка).
  - Новости о шоках у ИИ — только по топ-5.
  - Граница с `historical-events` — как предложено.
- **design-flaw-recalls.**
  - По истечении таймера — заплатка.
  - Потолок стоимости отзыва — 30 % выручки за 12 месяцев.
  - Статьи расходов — Fines и Development.
  - Переключатель спешки в конструкторе — Should.
  - Осторожность ИИ после брака — в `rival-personalities` (`IFlawResponseBias`).
- **historical-events.**
  - Катастрофы и пандемия — отдельная категория, по умолчанию выключена.
  - Режим `adaptive`.
  - Фолбэк ценовых войн без `rival-personalities` допустим.
  - Экспортный контроль — без регионов.
  - Будущие события в хронике скрываются.
  - Криптобумы 2017 и 2021 годов — здесь, с эффектом на спрос GPU.
- **rival-personalities.**
  - Назначения характеров компаниям утверждены.
  - Характер становится виден после первой реакции.
  - Smear входит в набор.
  - Стоимость Poach — как предложено.
  - Скидка `foundry_partner` есть.
  - «Туманность» разведки — Should.
  - Владеет ценовыми войнами: `ApplyPriceCut` / `RestorePriceCut` в `IRivalPersonalitiesApi`.
- **press-reviews.**
  - Задержка обзора — 7–21 день.
  - Отдельных обзоров вариантов CPU нет.
  - Сила эффектов принята.
  - Издания вымышленные.
  - Дрейф репутации — в ядре.
  - Ажиотаж складывается мультипликативно, в общем пределе ядра.
  - Обзоры ИИ приходят дайджестом.
- **gpu-product-line.**
  - Fabless — абстрактный аутсорс.
  - Чистый литейщик открыть GPU не может.
  - ИИ-вендоры линии не резервируют.
  - Переключатель «CPU в приоритете» есть.
  - Соперники — реальные имена.
  - Подразделение стоит `2,5e7 × инфляция`.
  - iGPU и системный уровень — вне скоупа.
  - Консольные OEM-заказы — Could.
